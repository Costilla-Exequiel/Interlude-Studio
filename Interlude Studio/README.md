# Interlude Studio

Interlude Studio es una página web colaborativa desarrollada por tres integrantes como parte de un proyecto académico. El sitio presenta nuestros servicios de prototipado 3D, incluyendo diseño CAD, impresión FDM/SLA y acabados profesionales.

## 🌐 Estructura del proyecto

- `index.html`: estructura principal del sitio
- `style.css`: estilos visuales y diseño responsivo
- `script.js`: interacciones básicas y validación de formulario

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## 📱 Diseño responsivo

El sitio se adapta a pantallas móviles gracias a media queries en el archivo `style.css`.

## 📬 Formulario de contacto

Incluye validación básica en el cliente. No envía datos a un servidor externo.

## 👥 Integrantes del equipo

- Exequiel — Front-end y coordinación
- Integrante 2 — Estilos y diseño
- Integrante 3 — Interacciones y validación

## 🚀 Cómo colaborar

1. Clonar el repositorio
2. Crear una rama con tu nombre
3. Subir tu archivo (`index.html`, `style.css` o `script.js`)
4. Crear un Pull Request para revisión
